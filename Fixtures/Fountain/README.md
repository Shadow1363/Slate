# Fountain reference scripts

Sample screenplays by Stu Maschwitz, published on [fountain.io](https://fountain.io) as Fountain examples, with the PDFs the site distributes alongside them. They are used only as test fixtures: the Publish tests check Slate's page breaks against these PDFs.

| File | Source |
| --- | --- |
| `Brick-and-Steel.fountain`, `.pdf` | https://fountain.io/_downloads/Brick-&-Steel.fountain and `.pdf` |
| `The-Last-Birthday-Card.fountain`, `.pdf` | https://fountain.io/_downloads/The-Last-Birthday-Card.fountain and `.pdf` |

Downloaded 2026-11-22. The two PDFs use different layouts: *Brick & Steel* uses the standard 1.5" left margin and two blank lines before scene headings; *The Last Birthday Card* is shifted 0.25" left, uses one blank line before headings and wider dialogue. The tests use a matching format for each.
